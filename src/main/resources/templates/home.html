Baza de date: PostgreSQL profil prod

Aplicatia ruleaza cu PostgreSQL (Neon sau alt host). Datele persista intre restart-uri; discul ephemeral al hostului nu e folosit.

Baza de date: MySQL (profil docker)

Aplicatia ruleaza cu MySQL (de obicei prin Docker Compose). Datele persista intre restart-uri.

Pentru inspectie locala poti folosi phpMyAdmin (daca e pornit via Compose) la http://localhost:8081. Credentialele DB sunt cele din variabilele de mediu (MYSQL_ROOT_PASSWORD / SPRING_DATASOURCE_*).

Seteaza utilizatorul/parola admin prin APP_ADMIN_USERNAME / APP_ADMIN_PASSWORD (implicit: admin / admin123 pentru dezvoltare locala).
